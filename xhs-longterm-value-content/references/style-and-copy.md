# Style and copy

## Build a style profile before writing

Inspect samples for these observable choices:

| Layer | Extract |
| --- | --- |
| Positioning | Audience, spending attitude, recurring promise, and product categories |
| Cover system | Background color, product count, grid, title placement, type weight, whitespace |
| Product-card system | Product scale, white space, title/price line, body line count, text alignment |
| Voice | First-person distance, sentence length, colloquialisms, certainty level, emoji/filler use |
| Value logic | Price anchoring, use scenes, comparisons, styling outcomes, purchase friction |
| Caption | Opening rhythm, item order, hashtags, calls to save/comment |

Describe the pattern in neutral, reusable terms. Never write “copy this account”; write what the account consistently does.

## Copy structure for one product card

Use 2–4 short lines after “产品名 + 价格”. Each line has a job:

1. Budget entry or aesthetic promise: what the buyer gets for the price.
2. Specific usage: a tangible feature or a daily scene.
3. Value conclusion: why it earns a place in a long-term, low-budget rotation.

Example pattern, not a line to copy:

Price gives a basic outfit a clearer finishing point.
It works for class and commuting, so it is not reserved for rare occasions.
One deliberate purchase supports several existing looks.

Use the account’s established voice. For a friendly “女大” account, first-person markers such as “本女子” can work when samples support them. Keep claims personal and concrete; avoid exaggerated performance promises.

## Whole-post caption structure

Title:
Audience identity｜budget/value promise｜theme

Opening:
- Theme/palette.
- One sentence defining the value rule.

Body:
- Six numbered products with price.
- 1–3 sentences each, richer than the card but still skimmable.

Close:
- A save/comment prompt only if it fits the account.

Hashtags:
- 4–8 intent and category tags; do not stuff unrelated trending tags.

## Originality check

Before delivery, compare the draft with benchmark notes:

- Keep only transferable structures: price anchor, scenario, value conclusion.
- Replace any distinctive benchmark phrase with fresh, account-appropriate language.
- Do not attribute personal use, a gift, a test, or long-term ownership unless the creator supplied that fact.
- Do not invent an “official price” or an unverified specification.
