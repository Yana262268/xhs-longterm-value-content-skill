# 长期主义女大好物内容 Skill

一个面向小红书好物账号的内容生产 Skill。它把“找选题 → 看对标 → 核验产品 → 写文案 → 做图 → 交付复盘”拆成可复用的流程，适合“长期主义女大”“花小钱装大杯”“低预算悦己”“通勤好物”等内容方向。

## 能做什么

- 从小红书、抖音公开内容和热点资料中提炼近两周的选题信号。
- 结合账号历史内容拆出选品规则、文案口吻、封面结构和产品卡信息密度。
- 用品牌官网或官方商城核验产品型号、配色、图片与价格。
- 选出颜色统一、可干净抠图、能解释“花小钱装大杯”的六件产品。
- 生成原创标题、发布文案、六张单品卡、封面、来源记录和发布包。
- 在用户修正颜色、标题、密度、选品或图片来源后，同步重排所有相关成品。

## 核心设计

### 1. 三类信息，各司其职

账号样本和对标笔记负责回答“这个账号怎么说”；公开趋势负责回答“现在大家在讨论什么”；品牌官网负责回答“产品到底是什么、卖多少钱、长什么样”。三者不混用，减少内容看似热门但信息不准的问题。

### 2. 把“花小钱装大杯”写成证据

每件入选产品都要能回答四件事：花多少钱、哪里显得更完整、在哪些场景会用、为什么少买重复品。这样不会把“便宜”直接等同于“值得买”。

### 3. 图文一体

封面用六个同色系的真实产品切图完成 3+3 排布；单品页只出现产品、名称、价格和正文。图片来源、价格备注和调研过程放在独立来源文件，既能回溯，也不干扰首页视觉。

## 安装

### 方式一：下载 ZIP

下载仓库 Release 中的 xhs-longterm-value-content-skill.zip，解压到 Codex Skills 目录：

~~~
mkdir -p "$HOME/.codex/skills"
unzip xhs-longterm-value-content-skill.zip -d "$HOME/.codex/skills"
~~~

重启或刷新工作台后，用 $xhs-longterm-value-content 调用。

### 方式二：克隆仓库

~~~
git clone https://github.com/你的用户名/xhs-longterm-value-content-skill.git
cp -R xhs-longterm-value-content-skill/xhs-longterm-value-content "$HOME/.codex/skills/"
~~~

## 调用示例

~~~
用 $xhs-longterm-value-content 为我的小红书账号做一期：
主题：长期主义女大花小钱装大杯好物分享
色系：粉紫色
数量：6 件
请研究近两周小红书和抖音公开内容，官网核验产品，
输出封面、6 张单品图、发布文案、选品来源和 ZIP。
~~~

## 输出结构

~~~
project/
├── research/        # 对标、趋势和选品记录
├── copy/            # 发布文案与单品卡文案
├── assets/final/    # 封面和单品图
├── review.md        # 质量检查与限制
└── publish-images.zip
~~~

## 适用范围与限制

Skill 使用公开内容做研究线索，不承诺覆盖平台全部内容；品牌价格与库存会变化，需要在发布前复查。官方产品图仅用于当前创作交付，不建议随 Skill 源码一同再分发。
